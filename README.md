# Little Games Studio

A monorepo for eight original Android games. Each game will live in its own folder under `apps/`, with independent identity, assets, and build output. Shared tooling and release notes will live at the repository root and under `docs/`.

## Games

- **Star Sprout Sprint** — endless runner with original characters, environments, music, and progression.
- **Pocket Pals** — virtual pet care and mini-games.
- **Mimi's Style Studio** — pet care, dress-up, and activities.
- **Slice Galaxy** — arcade fruit-slicing gameplay with original art and effects.
- **Bumpy Trail Rally** — physics-based driving across original courses.
- **Tiny Tastes Kitchen** — playful cooking and food experiments.
- **Little World Stories** — interactive pretend-play locations and activities.
- **ColorPop Doodle** — free drawing and colorful artwork.

## Project status

The app folders are being set up. We will build and review one playable prototype at a time, then expand it based on feedback. APKs are generated from the source projects for device testing; store release setup is documented separately once the apps and monetization choices are defined.

All games use original names, characters, visuals, music, levels, and code. They may use broad genre conventions as inspiration, not another product's protected content.
